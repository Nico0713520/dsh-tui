# DeepSeek brand asset

`deepseek-whale.svg` is the unmodified blue whale mark served by the official
DeepSeek API documentation site. `deepseek-whale.png.base64` is a deterministic
63 × 46 transparent PNG cache used only for terminal inline-image protocols.

The text-terminal Braille fallback in `src/ui/brand-logo.ts` is sampled from
the same silhouette. It is a rendering fallback, not a replacement logo.

DeepSeek and its whale mark belong to their respective owner. This repository
is an independent community TUI and is not an official DeepSeek product.
