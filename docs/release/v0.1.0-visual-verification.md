## Automated lifecycle — PASS

- The first frame accepts input while backend/session startup continues.
- The full welcome appears only before the first user item.
- First submit removes the full whale and leaves one identity row at transcript
  position zero; a long PTY conversation proves that row is not fixed chrome.
- `/status` opens locally and never reaches the Echo/model backend.
- `Ctrl+O` toggles tool detail locally and never enters the editor.
- Tool completion replaces the pending component in place.
- Approval Escape does not cancel the ACP session; allow/reject remain limited
  to options supplied by ACP.
- Resizing through 80, 48, and 32 columns produced no overflow.
- DeepSeek Light emitted the canvas background and a terminal reset on exit.
- `NO_COLOR` retained the full layout without decorative RGB sequences.
- Full/reduced/off modes preserve the same labels; overlays pause the shared
  visual timer; the official whale is static in every mode.
